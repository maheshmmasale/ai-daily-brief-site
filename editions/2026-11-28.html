Top Storiescompany claim Anthropic · 2026-11-25

Migrating our Messages API to Rust

Anthropic moved its Messages API — the main route customers and its own apps reach Claude — from Python to Rust, after traffic grew roughly 1,800x since early 2024. Claude wrote the first version of the core request path in about a week, but the hard part was proving parity: the team turned the production Python API into a verifier, shadowing live traffic and comparing every stage before and after the model call, with agents triaging each new kind of difference. The result uses about 70% less CPU per request and cuts median time to first token by about 20%, shipped without downtime or freezing feature work.

Why it matters: A rare inside look at migrating a live frontier API with AI doing the rewrite — and the verification loop, not the code generation, was the bottleneck.

Top Storiescompany claim Together AI · 2026-11-26

Distilling Kimi-K3.1-Pro into Qwen3.8-27B: Teaching a model a new language

Qwen3.8-27B, a popular small model, couldn't write Lao — it answered in Thai, scoring 5.5 chrF++ on FLORES-200 while Kimi-K3.1-Pro scored 47.5. Together used off-policy distillation: Kimi translated about 3,800 sentences, and a LoRA fine-tune on Qwen3.8-27B reached 44.3, 93% of the teacher, writing Lao on every test sentence. The catch was catastrophic forgetting — training on Lao alone collapsed Thai from 46.7 to 5.3 — fixed by mixing in Thai teacher data. All experiments together cost $260. The same recipe improved Northern Sotho, Yoruba and Zulu.

Why it matters: A cheap, reproducible recipe for patching a small model's blind spots — and a clean demo that you must measure what you might break, not just what you're fixing.

Frontier Labs & Big Techcompany claim Databricks · 2026-11-26

Rethinking read replicas for the lakebase architecture

Traditional Postgres read replicas are physical clones — their own instance, storage and copy of the data — taking minutes to hours to create and billing 24/7. In Databricks' Lakebase Postgres, compute and storage are separate, so a read replica is just another compute attached to the same storage: ready in seconds, adding no storage cost, autoscaling with read load and scaling to zero after 5 minutes idle. The post walks through the architecture (safekeepers, pageservers, GetPage@LSN) and seven use cases, from absorbing traffic spikes to giving AI agents their own read-only compute.

Why it matters: It turns replicas from something you provision in advance into something you spin up per job — a genuinely different cost model for Postgres reads.

Startups to Watchcompany claim Glean · 2026-11-26

Token Efficiency in Enterprise AI: What Matters Most

Glean argues most enterprise teams optimize the wrong thing — prompt wording — when the real token waste sits upstream: retrieving too many documents, sending whole documents when a passage would do, and repeating context across workflow steps. Its four-layer framework runs retrieval quality first (precision over recall, permission-aware), then passage-level selection, then prompt structure for control rather than compression, then orchestration that summarizes intermediate state instead of reloading it. The metric to watch is outcome per token, including retrieval precision and context utilization rate, not raw token counts.

Why it matters: As context windows grow, the expensive failure mode isn't the prompt — it's a retrieval layer that ships noise to the model on every step.

Startups to Watchcompany claim ElevenLabs · 2026-11-27

Agent-to-agent communication: How AI agents work together

An explainer of how multi-agent systems coordinate: the A2A protocol (from Google) connects agents to each other via agent cards, tasks, messages and artifacts, while MCP (from Anthropic) connects agents to tools and data — they solve different problems and are usually used together. A viable agent network needs four capabilities: discovery, delegation, state and context control, and modality neutrality. ElevenLabs notes its own ElevenAgents handles handoffs natively via agent transfer and Workflows rather than A2A, and supports MCP as both hosted server and client.

Why it matters: A clear map of the A2A/MCP split — the two protocols every multi-agent stack now has to reckon with.

Least-privilege access for inference workloads

Inference workloads often fetch private weights or LoRA adapters at runtime, and the easy setup — a permanent cloud key plus open internet — hands a model far more access than it needs. Baseten's walkthrough replaces long-lived keys with OIDC short-lived tokens, mirrors weights once into a sealed, read-only BDN volume so replicas never touch the bucket, and restricts egress to an allow-list of hosts. The post gives the actual config: volume sync commands, runtime OIDC setup, and an IAM policy scoped to one adapter prefix.

Why it matters: A concrete least-privilege recipe for serving — the kind of thing that matters the day a dependency in your inference container turns out to be malicious.

Engineering & Researchcompany claim Crusoe · 2026-11-25

RDMA memory registration overhead in GPU VMs explained

When a GPU workload registers memory for RDMA inside a VM, the NIC keeps its context in host RAM the VM can't see — and RDMA-heavy workloads like disaggregated inference and MoE training have pushed a single NIC to 4-6 GiB of it. Crusoe traces the cost: translation entries grow with registered bytes (a 265 GiB registration costs about 530 MiB at 4 KiB pages, about 1 MiB at 2 MiB pages), and shows how it measures the hidden memory via the NIC driver's debugfs counters and enforces per-VF budgets in ConnectX-7 firmware so one tenant can't starve a host.

Why it matters: A hidden tax on large-scale GPU networking, explained with real fleet numbers — and the fix (bigger pages, register once, reuse) is immediately applicable.

Sigma Rules: Write, Convert, and Test Detections

Sigma rules are the open, vendor-neutral YAML format for SIEM detections — SigmaHQ held 3,807 of them as of November 17 — converting to Splunk, Sentinel, Elastic and 25+ other formats. Why it matters: Detection-as-code only works if the detections actually fire — this is the field guide to proving it, with the current state of the Sigma ecosystem.

Worth Your Timecompany claim Hugging Face · 2026-11-25

Where scientists draw the line on AI agents

The Allen Institute for AI interviewed 17 scientists across the natural, applied and social sciences about agentic AI in research, and distilled five dimensions of scientific trust: validation, privacy, objectivity, accountability and transparency. Researchers welcome agents for repetitive work but want to inspect how results were produced, know what data was accessed, and keep intellectual contribution — one biologist refused AI help generating research ideas; a political scientist rewrote a whole paper after losing track of what was AI and what was theirs. The authors propose participatory benchmarks in which scientists help define what agents should be tested against.

Why it matters: The most grounded account yet of what researchers actually want from science agents — verification and agency, not just correct answers.
